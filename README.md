# Escoramento UI Case Study

Front-end case study focused on UI reconstruction, reusable component architecture and responsive layout strategies.  
Built with **Next.js**, **Material UI (MUI)** and a **custom design system**.

---

## 📌 Project Overview

This project is a front-end architecture study inspired by the Escoramento.com platform.

The main goal is not to replicate the system behavior, but to explore:

- Component-driven design
- Design system structure
- Responsive layout strategies
- Visual consistency
- Scalability patterns

---

## 🧱 Tech Stack

- Next.js (App Router)
- React
- TypeScript
- Material UI (MUI)
- Custom Design System

---

## 🎯 Focus Areas

This case study explores:

✔ Reusable component architecture  
✔ Layout composition patterns  
✔ Design token strategy  
✔ Responsive UI behavior  
✔ Visual hierarchy & spacing  
✔ Theming & styling consistency
